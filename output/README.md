# Evaluation output

`evaluation.json` is generated by the deterministic prompt-quality heuristic.

The metric is intentionally limited to prompt structure signals:
- task clarity
- context
- constraints
- output format
- examples

It is **not** a measurement of an LLM's factual accuracy, usefulness, latency, or safety.

Generate locally:

```bash
python -m src.evaluate
```

The next stage is to add model-backed evaluation with a fixed dataset and explicit agreement/error analysis.
