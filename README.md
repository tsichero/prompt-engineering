# Prompt Engineering Lab — Systematic Prompt Evaluation

> **Portfolio project · Prompt Engineering · Generative AI · Evaluation**

Laboratório prático para demonstrar **Engenharia de Prompt como processo técnico**, indo além de uma coleção de prompts.

O projeto organiza experimentos de **hipótese → prompt → execução → avaliação → comparação → melhoria**, com foco em qualidade, consistência, formato de saída e redução de falhas.

## Objetivo

Investigar como diferentes estratégias de prompting alteram o comportamento de um modelo e documentar os resultados de forma reproduzível.

## Experimentos

- Zero-shot prompting
- Few-shot prompting
- Role prompting
- Structured output
- Prompt chaining
- RAG-oriented prompting
- Instruções de restrição
- Técnicas para redução de respostas fora do contexto
- Comparação entre versões de prompt

## Critérios de avaliação

Cada experimento pode ser analisado por critérios como:

- aderência à instrução
- precisão
- completude
- consistência
- formato de saída
- groundedness/contextualização
- ocorrência de alucinação
- robustez a entradas diferentes
